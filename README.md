# Aprendiendo C

Este repositorio es mi espacio personal para aprender y practicar el lenguaje de programación C, desde lo más básico hasta conceptos más avanzados, según voy adquiriendo nuevos conocimientos.

## 📚 Contenido

Aquí encontrarás diversos programas y ejercicios que cubren temas como:

- **Fundamentos**: variables, tipos de datos, operadores, estructuras de control
- **Punteros y memoria**: punteros, asignación dinámica, arreglos
- **Estructuras y uniones**
- **Manejo de archivos**
- **Bibliotecas estándar de C**
- **Temas avanzados**: como procesamiento de audio, algoritmos, etc.

## 📁 Archivos

| Archivo | Descripción |
|---------|-------------|
| `main.c` | Programa principal / ejercicios básicos |
| `v.c` | Ejercicios con vectores/arreglos |
| `reservas.c` | Sistema de reservas (ejercicio práctico) |
| `audio.c` | Captura y análisis de audio con ALSA y FFT |
| `audio2.c` | Variante/experimento adicional con audio |
| `funcion_con_punteros.c` | Ejercicios con punteros y funciones |
| `array_punteros.c` | Arreglos de punteros |
| `estructura_puntero.c` | Estructuras con punteros |

## 🛠️ Compilación

Todos los programas se compilan con `gcc`. Ejemplo:

```bash
gcc -o programa main.c -lm
```

Algunos programas requieren librerías adicionales (como `alsa-lib` y `fftw3` para `audio.c`).

## 🎯 Propósito

Este repositorio no busca ser un proyecto formal, sino un cuaderno de bitácora donde voy experimentando y afianzando conceptos del lenguaje C a medida que los estudio.
